CANDY CRUSH STARTER PROJECT (SFML 3.0.2)

This is a Visual Studio starter scaffold. The game-logic function bodies are intentionally left as TODOs for your team to implement.

FILES
- CandyCrush_Starter.sln: open this solution in Visual Studio 2022 or 2026
- src/main.cpp: SFML window and game-function skeletons
- level.txt: sample level in the format from the project brief
- savegame.txt: empty file for your save feature

SET UP SFML
1. Install the 64-bit SFML 3.0.2 package that matches your Visual Studio compiler.
2. Extract it to C:\SFML-3.0.2, or edit SFML_DIR in the project properties to point to your SFML folder.
3. Open CandyCrush_Starter.sln.
4. Select x64 and Debug or Release, then build.
5. If Windows reports missing SFML DLL files when you run, copy the matching SFML DLL files from SFML's bin folder beside the built .exe.

STARTING YOUR WORK
- Search for TODO in src/main.cpp and split the functions between your team members.
- The stub functions do not implement gameplay. The starter currently only opens a window with a blank background.
- Keep level.txt and savegame.txt in the program's working directory when running from Visual Studio.
- The project brief says to submit without x64, Debug, and .vs build folders.
